# 조사 계획: 내생적 참여자 구성 · 학습 가치함수의 MILP 임베딩

## 목적

문헌 요약이 아니라 **갭 특정**이다. 산출물의 성패는 아래 두 질문에 답하는지로 판단한다.
1. 우리 설정(기간별 매칭 + 잉여배분 결정이 다음 기간 참여자 집합을 바꾸는 동적 모형)과
   가장 가까운 선행연구가 무엇이고, 정확히 무엇이 다른가.
2. 학습된 비분리형 가치함수를 정수계획에 직접 임베딩한 ADP 선례가 있는가.
   없다면 그것이 우리 방법론 기여의 자리이고, 있다면 우리는 그 위에서 무엇을 더하는가.

## 주요 질문

주제 A: `ref/literature-review.md`의 A1–A5.
주제 B: `ref/literature-review.md`의 B1–B6.
우선순위: B3·B4 (비분리형 VFA를 IP에 넣은 선례, leave-one-out 차분 근사의 기존 용어와 지적된 한계)와
A2 (잉여배분을 기간별 결정변수로 둔 동적 모형의 존재 여부)가 갭 판정의 분기점이다.

## 자료 유형과 기간

- 저널 논문 우선(SCIE/SSCI Q1, OR/OM 주요 저널), ML 주요 학회 논문, arXiv 프리프린트(연도 확인 필수).
- 방법론 원전(ADP 근사구조, 신경망 MILP 정식화)은 연도 제한 없음. 응용 문헌은 2015년 이후 우선.
- 검색 경로: WebSearch, OpenAlex API(`api.openalex.org`, 키 불필요, 인용 그래프 순회 가능),
  arXiv API, Semantic Scholar. 페이월 전문은 초록·인용 정보까지만 쓰고 그렇게 표시한다.

분리형 근사의 부정확성 / 분리형 vs 비분리형 비교 / 증분 가치를 최적화 계수로 /
유지 가치 비례 배분의 1차 조건 / **부호 반전(증분 > 독립)이 처음**.

주문자 0~0.9%). 신뢰도 구조 논증의 전제가 충족된다.
