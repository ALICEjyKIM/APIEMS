## 설정

- 상태 48개: 평가 seed 반복 0~7 × 기간 6·12·18 × Myopic·Rule (정책별 24개).
- 공급자 관측 929개 (Myopic 434, Rule 495). 상태마다 V(S)와 V(S∖i)를 같은 미래 키로 쟀다.
- c_i 잡음: 평균 71.3, 표준편차 136.5, MC 표준오차 평균 40.6, 신뢰도 0.90 (설명력 상한 R² ≈ 0.90).
- own feature: 총 공급가능량, 공급 품목 수, 공급가격 수준(기준가 대비) 평균·최솟값, hS, 직전 재참여확률 rs, 재임 기간.
- context feature: 공급 품목의 대체 공급자 수 최소·평균, 대체 용량 최소·평균, 품목 용량 중 자기 몫 최대, 공급 품목 요구량 합, 요구량/용량 최대·평균, hI 최대·평균,
  연결 주문자 수·묶음 전체 요구량·hB 평균·최소, 연결 주문자 묶음의 최소 품목 degree 평균·bottleneck(≤ 2) 묶음 수, 관련 대기 후보 수·용량·최소 대기 기간, 빼면 0명 품목 발생 여부, 공급 품목 최소 degree.
- 기준 환경(L = 2)의 자연 상태에서는 대기 후보의 남은 기간이 모두 1이다. 회복 가능성은 자연 상태에서 "관련 대기 후보가 있는가"로만 변하고, 대기 기간은 섭동으로만 바꿀 수 있다.

## 자연 짝 (own feature가 비슷하고 context 하나가 다른 공급자)

같은 품목 수, own feature 표준화 거리 ≤ 0.5 (실제 평균 0.14~0.17)인 짝을 탐욕적으로 골랐다. c 차이 = 희소한 쪽 − 덜 희소한 쪽. CI는 짝 부트스트랩.

| context 기준 | 짝 | 평균 c 차이 [95% CI] | 양수 비율 | 유의 양 / 음 |
|---|---|---|---|---|
| 대체 공급자 최소 수 2 이상 적음 | 359 | +68.0 [+54.1, +82.3] | 0.73 | 0.29 / 0.04 |
| 빼면 0명 품목 발생 | 84 | +74.7 [+38.0, +110.2] | 0.71 | 0.30 / 0.06 |
| 요구량/용량 최대 0.5 이상 큼 | 396 | +41.5 [+29.2, +54.5] | 0.61 | 0.21 / 0.08 |
| hI 최대 0.15 이상 큼 | 317 | +25.0 [+9.2, +41.2] | 0.56 | 0.23 / 0.15 |
| 관련 대기 후보 없음 | 421 | +14.6 [+2.0, +27.2] | 0.57 | 0.15 / 0.11 |

주의: context 변수끼리 함께 움직인다. 대체 공급자 기준 짝은 요구량/용량도 평균 0.64 더 크다. 자연 짝은 "전반적으로 희소한 위치"의 효과를 보여주고, 변수 하나의 효과를 분리하지 않는다.

## 통제 섭동 (own feature 그대로, 주변 하나만 바꿈, 같은 미래 키)

24개 (상태, 공급자) 대상, Myopic·Rule 상태 12개씩.

| 섭동 | 적용 | 평균 Δc [95% CI] | 기대 부호 | 부호 일치 | 유의 일치 / 반대 |
|---|---|---|---|---|---|
| 대체 공급자 1명 제거 | 20 | +33.1 [+9.5, +59.0] | + | 0.80 | 0.15 / 0.00 |
| 대기 후보 1명 즉시 활동 (대체 +1) | 18 | +1.9 [−25.6, +39.7] | − | 0.67 | 0.06 / 0.06 |
| 관련 대기 후보 2기간 늦춤 | 18 | +13.3 [−3.3, +31.6] | + | 0.56 | 0.06 / 0.00 |
| 연결 주문자 수량 1.5배 | 24 | +27.2 [+2.6, +54.6] | + | 0.79 | 0.12 / 0.00 |
| 연결 주문자 수량 0.5배 | 24 | −33.9 [−59.7, −9.7] | − | 0.71 | 0.17 / 0.00 |

- 자리 수가 고정이라 공급자를 더하는 현실적 경로는 대기 후보를 앞당기는 것뿐이다. 그래서 "대체 +1"은 대기 후보 −1과 함께 바뀌어 효과가 상쇄될 수 있다. 결과는 0과 구분되지 않는다.
- "빠른 onboarding"은 자연 대기 기간이 이미 1이라 "대체 +1"과 같은 조작이 되어 따로 두지 않았다.
- 섭동 하나의 Δc 표준오차는 35~43으로 커서 개별 대상의 유의 비율은 낮다.

## 세 관계

- 대체 공급자 수 ↓ → c ↑: 지지. 자연 구간 평균 c는 대체 0명 198, 1명 136, 2명 66, 3명 이상 22. 자연 짝 +68, 섭동(제거) +33.
- 연결 수요·tightness ↑ → c ↑: 지지. 요구량/용량 3분위 32 → 65 → 117, hI 3분위 46 → 58 → 109. 자연 짝 +42 / +25, 수량 섭동 +27 / −34.
- 회복 가능성 (onboarding 대기 ↑ → c ↑): 약함. 관련 대기 후보가 없으면 c가 89 vs 66, 자연 짝 +15 [+2, +27]. 대기 2기간 늦춤은 +13 [−3, +32]로 0과 구분되지 않는다. L = 2에서는 대기가 짧아 회복 경로의 차이가 작다.

## 설명력 (선형 ridge, λ = 1 고정, 반복 단위 leave-one-out 교차검증)

| 모형 | R² | MAE | 상태 내 Spearman | 상태 내 상위 3 적중 |
|---|---|---|---|---|
| own only | 0.395 | 74.7 | 0.571 | 0.50 |
| own + context | 0.461 | 70.1 | 0.655 | 0.53 |

- MAE 개선 +4.6 [+1.4, +8.2] (반복 블록 부트스트랩). context를 넣으면 설명력과 순위 정확도가 유의하게 좋아진다.
- 개선 폭은 R² 0.07로 작다. 신뢰도 상한 0.90과의 차이(0.44)가 크다.
- own feature 중 총 공급가능량(+)과 품목 수(−)의 계수가 가장 크다. 같은 용량이면 품목이 적을수록(용량이 몰릴수록) 가치가 크다.
- 구간 분석에서 대체 공급자 수와 c의 관계는 강하게 비선형이다 (198 → 136 → 66 → 22). 선형 모형이 남긴 차이가 요약 지표의 비선형성 때문인지, 요약으로 담기지 않는 연결 구조 때문인지는 이 진단으로 가를 수 없다.

## 판정

- Case A (context 무관)는 아니다. 자연 짝과 섭동 모두에서 대체 공급자 수와 수요·tightness에 따라 c가 기대 방향으로 체계적으로 달라진다. own + context 모형의 개선도 유의하다.
- Case B의 조건을 만족한다. 다만 선형 요약 모형의 개선은 작다 (R² +0.07).
- Case C와 D는 아직 구분할 수 없다. 남은 설명 여지(R² 0.46 vs 상한 0.90)가 비선형 요약 함수로 메워질지, 관계 구조가 필요한지는 비선형 모형이 있어야 판단된다.
- 회복 가능성 축은 기준 환경에서 약하다.
