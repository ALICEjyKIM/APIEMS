## 2. 후보 A: 재참여 조건부 쿠폰을 지급하지 않는 충분조건

현재 쿠폰의 경제성을 분석하는 제한 모형이다. 위 논문들의 향후 과제를 직접 해결했다고 주장하지 않는다.

### 가정

1. 현재 기간 청산을 고정한다. m, 거래 결과, 제외자 집합은 쿠폰에 따라 변하지 않는다.
2. 쿠폰 대상 i는 현재 거래하지 않았다. 재참여 확률은
   p_i(k_i) = sigmoid(a_i + b_i k_i), b_i > 0 이다.
3. k_i >= 0은 다음 기간에 재참여할 때 지급한다. 조건부로 Z_i는 독립 Bernoulli(p_i(k_i))다.
4. 쿠폰은 Z와 지급액을 통해서만 미래에 영향을 준다. Z가 주어졌을 때 그 외 미래 상태의 조건부 법칙은 k와 무관하다.
5. V(Z)는 이번에 발행한 쿠폰의 지급 비용을 제외한 미래 기대가치다. 이후 정책을 고정한 가치 또는 위 가정과 분리 가능한 최적 continuation value를 사용할 수 있다. 지급액이 별도의 현금·예산 제약을 만들지는 않는다.
6. 모든 Z_{-i}에 대해 D_i(Z_{-i}) = V(1,Z_{-i}) - V(0,Z_{-i}) <= B_i, B_i >= 0 이다. B_i는 평균 추정치가 아닌 유효한 상한이어야 한다.

현재 제외자에서는 거래 지표 e=0이므로 기준점 항 eG는 0이고, 쿠폰이 현재 기준점 r을 갱신하지 않는다.
따라서 현재 재참여 식에 조건부로 대응하는 b_i는 beta1_kind * cpn_w / w_i다.
여기서 w_i는 코드의 잉여율 분모다. 공개 배분 가중치 omega_i와 구분해야 한다.
이 대응은 완전한 조건부 시장에 대한 것이다. 입찰 전 부분 관측 정책에서 B_i를 아는 것은 별도 문제다.

### 명제 A1

모든 i에 대해 b_i * (1-p_i(0)) * B_i <= 1 이면,

F(k) = E[V(Z(k))] - sum_i p_i(k_i) k_i

는 각 좌표 k_i에 대해 비증가한다. 따라서 0을 포함하는 쿠폰 가능집합에서 모든 쿠폰을 0으로 두는 것이 최적이다.
V가 additive일 필요는 없다. 참여자 간 complementarity도 허용한다.

### 증명

다른 쿠폰을 고정하면 E[V]의 p_i에 대한 미분은 E[D_i(Z_{-i})]다.
p_i' = b_i p_i(1-p_i)이므로

dF/dk_i = p_i * { b_i(1-p_i) * (E[D_i]-k_i) - 1 }.

E[D_i]-k_i <= 0이면 미분은 음수다.
E[D_i]-k_i > 0이면 p_i(k_i) >= p_i(0), E[D_i] <= B_i를 사용해

b_i(1-p_i)(E[D_i]-k_i) <= b_i(1-p_i(0))B_i <= 1.

따라서 미분은 항상 0 이하다. 어느 k도 한 좌표씩 0으로 낮추면 F가 줄지 않는다. 끝.

이 명제는 m=1이 최적임을 증명하지 않는다. 특정 m과 현재 청산을 고정한 쿠폰 결정에 대한 조건이다.
현재 30기간 시장이 이 조건을 만족하는지도 아직 확인하지 않았다.

### 명제 A2: 한 참여자일 때의 정확한 경계

대상이 한 명이고, 재참여 여부에 따른 미래 가치 차이가 D >= 0으로 고정이면

F(k)-F(0) = [p(k)-p(0)]D - p(k)k.

연속 쿠폰 k in [0,K], K>0에서 k=0이 최적인 필요충분조건은

b * (1-p(0)) * D <= 1.

위 부등식이 반대면 F'(0)>0이므로 충분히 작은 양의 쿠폰이 이롭다.
F'의 부호를 정하는 H(k)=b(1-p(k))(D-k)-1은 0<=k<=D에서 엄격히 감소한다.
k>=D에서는 F'<0이다. 따라서 양의 내부 최적점이 있다면 유일하다.
해는 b(1-p(k))(D-k)=1을 풀고 상한 K를 적용해서 구할 수 있다.

주의: 현재 theta_grid처럼 쿠폰이 이산적이면 F'(0)>0만으로 이용 가능한 양의 후보가 유리하다고 결론 낼 수 없다.
또한 p(k)k는 새로 돌아온 사람뿐 아니라 쿠폰 없이도 돌아왔을 사람에게 지급하는 비용까지 포함한다.

### 보완성에 대한 작은 구성 예

두 참여자가 모두 돌아와야 다음 기간 gross margin R이 생긴다고 하자.
V(Z)=R Z_1 Z_2, 두 사람의 무지원 재참여 확률은 p0이고, 같은 쿠폰 k를 주면 p1>p0이 된다.

- 한 사람만 지원한 이득: R*p0*(p1-p0) - k*p1.
- 두 사람을 지원한 이득: R*(p1^2-p0^2) - 2*k*p1.

따라서

2*k*p1/(p1^2-p0^2) < R <= k*p1/[p0*(p1-p0)]

이면 같은 크기의 개별 지원은 이롭지 않아도 공동 지원은 이롭다.
이 구간은 p1>p0이면 비어 있지 않다.
이는 개별 지원의 한계 이득만으로 공동 지원을 배제할 수 없다는 예다.
연속 쿠폰 전체에 대해 개별 지원이 무익하다는 명제는 아니다.
이 예의 V를 현재 Chu 청산이 실제로 생성하는지는 별도 구성이 필요하다.

이론 검증: 임의의 비분리 V를 갖는 1~4명 모형에서 A1의 조건을 만족하도록 b를 정한 뒤 17,000개 쿠폰 조합을 열거했다. 위반은 없었다.

## 3. 후보 B: 두 품목 묶음의 제한 모형에서 정확한 flow 환원

Guo의 계산 효율성 과제와 주제가 연결되지만 Guo의 일반 MDA-DB를 해결하는 결과는 아니다.
현재 Chu형 배정 oracle의 제한 모형에 대한 도출이다.

### 가정

- 각 주문은 서로 다른 두 품목을 각각 1단위씩 요구한다. 주문은 all-or-nothing이다.
- 두 품목을 연결하는 주문 그래프가 bipartite이며 품목을 L,R로 나눈다.
- 품목별 공급 용량과 비용은 separable하다. 공급자 전체의 공통 용량 제약·고정비·품목 간 생산 비용은 없다.
- 단위 원가는 비음수다. 공급 자격과 품목별 용량은 고정한다.
- padding Q_c는 고정된 정수이며, Q_c단위를 공급할 수 있다고 가정한다. 현재처럼 가상 공급자로 이를 보장해도 된다.

C_c(d)를 품목 c의 가장 저렴한 d단위 공급 비용으로 두면, C_c는 정수 격자에서 convex하다.
주문 집합 X의 padded 목적값은

sum_{b in X}(W_b-f) - sum_c C_c(Q_c + deg_X(c)).

### 명제 B1

위 배정 문제는 min-cost circulation으로 정확히 환원할 수 있다.
단위 공급을 명시한 입력 크기 기준으로 polynomial-time에 풀 수 있다.
piecewise-linear 공급 구간도 같은 비용의 연속 arc capacity로 압축할 수 있다.

### 구성 및 증명

1. source s, sink t, 품목 L,R 노드를 만든다.
2. c in L에 s->c arc들을 둔다. k번째 단위의 비용은 C_c(Q_c+k)-C_c(Q_c+k-1), capacity는 1이다.
3. c in R에 c->t arc들을 같은 방식으로 둔다.
4. 주문 b=(l,r)에 l->r arc를 두고 capacity 1, 비용 -(W_b-f)를 준다.
5. t->s에 비용 0, capacity 주문 수의 arc를 둔다.

적분 circulation의 각 단위는 주문 하나를 선택하며 두 끝 품목에 정확히 1단위를 사용한다.
각 품목의 incremental cost가 비감소하므로 사용량에 대해 가장 저렴한 앞부분 arc를 택할 수 있다.
이에 따라 circulation 비용은 원래 목적값의 음수에서 상수 sum_c C_c(Q_c)를 뺀 값이다.
반대로 가능한 주문 선택은 같은 비용의 circulation으로 표현된다.
정수 capacity를 갖는 min-cost circulation에는 정수 최적해가 존재한다. 끝.

이 명제는 복수 수량 q_bc, 임의 묶음, 공통 공급자 용량, 비선형 규모의 경제를 다루지 않는다.
배정 oracle의 환원만 증명했다. 모든 threshold-price 부분문제와 tie-breaking의 동등성은 추가 검증해야 한다.
공급자당 여러 품목일 때의 IC는 별개이며 이 환원으로 복원되지 않는다.
기존 b-matching/convex-cost flow 결과의 적용일 가능성이 높아, 자체 신규성은 아직 주장하지 않는다.

수치 검증: 주문 8개짜리 시장 200개에서 256개 주문 선택 전수열거와 circulation LP의 목적값이 모두 일치했다.

## 5. 현재 결과 해석의 범위

- MC/여지 점검의 분기 후 정책은 기존 행동 정책이다. 상태 100개와 유한 표본의 교차 여지로 모든 적응적 장기 정책의 이득 부재를 증명하지 못한다.
- 현재 TD는 max backup이 아니다. 발산 점검 후 expected SARSA backup으로 바뀌었고, 행동 정책 가치를 평가해 한 번 개선한다. 이전 대화의 max backup 설명은 현재 코드와 다르다.
- 시장을 키운다고 한 기간 이윤 최적 m이 반드시 1보다 커지는 것은 아니다. 그런 상태를 찾아도 장기 정책과의 차이는 자동으로 생기지 않는다.
- 현재 발견은 기준 시장·후보·정책·표본의 평가 결과다. 고정 padding의 전역 최적성은 아직 증명하지 않았다.
