# SUM-GNN vs Context MLP: 공급자 c_i 설명력 (진단 s13)

작성 2026-10-13. PROC15H 고정, 목표는 diag s11의 Rule-continuation c_i (M = 40). 정책 성능이 아니다.
코드 `vfa/hgnn.py`, `result/diag_s13_graph.py`, `result/diag_s13_gnn.py`, `result/diag_s13_mc.py`. 원자료 `result/runs/diag_s13_gnn.json`, `diag_s13_pred.npz`, `diag_s13_expand.json`, `diag_s13_units/`.

## 그래프와 모형

- 노드: 주문자, 품목, 활동 공급자. 연결선: 주문자–품목(주문하면), 공급자–품목(공급하면), 양방향 메시지. 주문자–공급자 직접 연결과 hSI는 없다.
- 주문자 노드: 주문 품목 수, 총 요구수량, 주문 금액, 평균 마크업(제안가격 / 기준가), hB, 직전 재참여확률.
- 품목 노드: 기준가, hI, 대기 후보 공급가능량·수, 최소 대기 기간 (대기 후보는 그래프 노드가 아니라 품목 특징으로만 들어간다).
- 공급자 노드: Own MLP와 같은 own feature 7개.
- 연결선 특징: 주문자–품목 [요구수량, 마크업], 공급자–품목 [공급가능량, 공급가격 수준]. 노드·연결선 특징은 학습 그래프 기준 표준화.
- 품목의 활동 공급자 수, 총 공급가능량, 총 요구량은 main 입력에 넣지 않았다 (SUM 집계로 배우게 둠). 명시한 버전은 공정성 점검으로만 돌렸다.
- 구조: 종류별 입력 encoder → 층 0: 주문자·공급자 → 품목 SUM, 층 1: 품목 → 주문자·공급자 SUM, 층 2(3층일 때): 다시 → 품목. 공급자 출력 = MLP([공급자 표현, Σ 연결 품목 메시지]) → ĉ_i. 관계·층마다 메시지 함수가 따로 있다. V(S)가 아니라 공급자 노드마다 c_i를 직접 낸다.
- 파라미터 수: SUM-GNN 은닉 32/64/128에서 2층 11,553 / 43,585 / 169,089, 3층 14,849 / 56,321 / 219,137. Context MLP 2층 2,017 / 6,081 / 20,353, 3층 3,073 / 10,241 / 36,865. 같은 은닉 크기에서 GNN이 4~9배 크다.

## 예산과 분할

- 두 모형 모두 은닉 {32, 64, 128} × 층 {2, 3} × weight decay {0, 1e-3, 1e-2} = 18설정 × 초기화 seed 3개, Adam lr 1e-3, 전체 배치, 1000에폭까지 25에폭마다 검증 MSE 조기 종료, MSE 손실.
- Context MLP도 18설정으로 다시 학습했다 (s12의 9설정과 차이 R² −0.004).
- 분할은 s12와 같다: 반복 8개, fold마다 시험 1·검증 1(다음 반복)·학습 6. Huber 등 다른 손실은 돌리지 않았다.
- 부트스트랩 오류 수정: 같은 반복이 두 번 뽑힐 때 상태 내 지표(Spearman, 상위 3)가 섞이던 문제를 고쳤다 (s12 CI도 다시 냄).

## 판정

- 48상태 main: 순위(상태 내 Spearman)는 안정적으로 낫고 thin market에서 더 크다. R²·MAE·상위 3은 평균으로 크게 낫지만 반복 두 개에서 나빠 CI가 0을 포함한다.
- 96상태 보조: 모든 지표에서 안정적으로 낫고 thin market에서 더 크다. GNN은 데이터가 늘수록 계속 오르고 차이도 커졌다.
- Case B(그래프가 요약을 넘는 정보를 준다)에 해당한다. thin market에서 더 큰 개선은 Case C의 성격도 있다. 48상태만으로는 R² 차이가 확정되지 않았으므로, Case B 판단은 96상태 보조 결과에 기대고 있다.
- 남은 차이: SUM-GNN 0.735와 상한 0.90 사이 0.17.
- 주의: GNN이 파라미터가 4~9배 많다 (같은 설정 예산). 목표는 Rule-continuation c_i이고, 이 결과는 값 표현력에 대한 것이지 결정 성과에 대한 것이 아니다.

## GAT 근거

- SUM 집계로 구조 정보를 얻는다는 근거는 생겼다. attention이 필요하다는 근거(이웃마다 다른 가중이 필요한 패턴)는 이번 진단에 없다.
- 품목 degree를 명시해도 변화가 없어, 절대량(SUM)이 핵심 정보라는 처음 판단과 맞다. softmax attention은 절대량을 희석할 수 있다.
- GAT는 우선순위가 낮다. 먼저 학습된 ĉ가 결정에 쓸모 있는지 확인해야 한다 (실험 7에서 정확한 Rule-continuation c도 Myopic-sup을 넘지 못했다).
