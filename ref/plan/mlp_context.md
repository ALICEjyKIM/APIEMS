## 설정

- 분할: 반복 8개 기준 바깥 leave-one-rep-out. fold마다 시험 반복 1개, 검증 반복 1개(시험 다음 반복), 학습 6개. 같은 반복의 Myopic·Rule·여러 기간 상태가 한쪽에만 들어간다. 모든 모형이 같은 분할.
- MLP: `vfa/mlp.MLP` (은닉 2층 ReLU, Adam lr 1e-3, 전체 배치, 1000에폭까지 25에폭마다 검증 MSE 조기 종료). 입력·목표는 학습 기준 표준화.
- 설정 예산 (Own·Context 같음): 은닉 {32, 64, 128} × weight decay {0, 1e-3, 1e-2} = 9개 × 초기화 seed 3개. fold마다 검증 MSE(seed 평균)로 고르고 시험 예측은 seed 3개 평균.
- ridge: 기존 기준(λ = 1, 학습 7반복)과 같은 분할·같은 9개 λ 예산의 선택형을 함께 보고.
- 목표 c는 오른쪽 꼬리가 길다 (왜도 2.2, 1%·99% 분위 −101, 564). 의미를 바꾸는 변환은 하지 않고 표준화만 했다.
- 설명 상한 (MC 신뢰도): 전체 0.900, thin market(대체 공급자 ≤ 1, 278개) 0.912.

## 남은 차이의 성격

- 학습 곡선 (은닉 64, wd 0.01 고정, 시험 R²): Context MLP 학습 반복 2 → 4 → 6에서 0.426 → 0.496 → 0.512, Own MLP 0.400 → 0.418 → 0.411. Context MLP는 데이터가 늘면 아직 조금 오르지만 증가 폭이 줄고 있다.
- 잔차의 90%는 상태 안의 차이다 (상태 평균이 잔차 분산의 10%). 잡음을 뺀 상태 내 잔차 분산은 c 분산의 34%.
- 입력에 없는 사후 구조 지표를 계산해 잔차와 비교했다: 빼면 늘어나는 용량 부족, 빼면 묶음을 못 채우게 되는 주문자의 요구량(AON 노출), 단독 공급 품목 수. 이 지표들은 c와 상관이 있지만 (Spearman 0.50 / 0.37 / 0.24), Context MLP 잔차와는 거의 상관이 없다 (0.05 / 0.05 / −0.06). 잔차를 이 지표로 설명한 교차검증 R²는 0.004.
- 입력(own + context, 표준화)이 가장 가까운 짝 100개: 평균 거리 0.29, c 차이가 MC 잡음 대비 z > 2인 비율 0.14 (잡음만이면 0.05), z 중앙값 0.92. 입력이 비슷한데 c가 다른 경우가 잡음보다 조금 많지만 대부분은 잡음 범위다.
- 큰 오차 15개는 대부분 실제 c가 매우 큰(565~987) 공급자를 작게 예측한 경우다. 반복 1 기간 6 상태에서 3개가 나왔다. 일부는 요약 지표가 "대체 공급자 4명, 0명 발생 없음"인데 c가 774다 (빼면 용량 부족 57). 꼬리가 긴 목표를 MSE로 맞추며 극단값을 줄여 예측하는 효과도 섞여 있다.

## 판정

- Case A가 아니다: Context MLP − Own MLP가 유의하게 양수다 (R² +0.09, MAE −8.0, Spearman +0.06).
- Case B도 아니다: Context MLP R² 0.51로 상한 0.90과 차이가 크다.
- Case C에 해당한다: context는 중요하지만 지금 요약으로는 설명이 불완전하다.
- Case D의 직접 증거는 약하다: 잔차가 사후 구조 지표(용량 부족, AON 노출, 단독 공급)와 관계가 없고, 입력이 비슷한 짝의 차이도 대부분 잡음 범위다. 남은 차이가 연결 구조 때문인지, 데이터 양(학습 곡선이 아직 오름)·꼬리가 긴 목표·Rule-continuation 미래 경로의 변동 때문인지 이 진단으로는 가를 수 없다.
